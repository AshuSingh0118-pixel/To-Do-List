# To-Do-List
A simple browser-based To-Do List where you can add, edit, and delete tasks, All tasks are saved automatically using localStorage - so your list stays even after refreshing the page. Includes a dark/light mode toggle.

## Features
- Add, edit, and delete tasks
- Data saved in browser (localStorage)
- Dark / Light mode toggle


## Built With
- HTML5
- CSS3
- JavaScript (Vanilla)
